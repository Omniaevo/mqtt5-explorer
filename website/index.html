The MQTT client built for MQTT 5

MQTT5 Explorer is a free, open source desktop MQTT client for Windows, macOS and Linux. Browse, search and publish on MQTT brokers with full support for MQTT 5: properties, user properties and more. MQTT 3.1 and 3.1.1 work too.

mqtt://mqtts://ws://wss://

Features

  • Full MQTT 5 support

    Read and send message properties and user properties. MQTT 3.1 and 3.1.1 are also supported. TLS with CA and client certificates.

  • Parallel connections

    Each connection opens in its own tab. Several brokers stay live at the same time, with a counter for new messages.

  • Topic tree

    Topics show as a tree with the last value inline. Open a topic to see its payload, history and properties.

  • Advanced search

    Search topic names, or search inside payloads and properties with query::. Case sensitive, whole word and regex modes.

  • Notifications and logging

    Set trigger conditions with or / and. Get a desktop notification or write the matching messages to a file.

  • Publish

    Publish messages on any topic from the same view where you read them.

  • Pinned tabs and quick connect

    Pin your saved connections. Type a broker URL in the Home search and press Enter to connect at once.

  • Your look

    Light and dark themes, your own primary color, font size and 9 Home wallpapers.

  • Keyboard first

    Shortcuts for tabs, search, settings and more. Press Ctrl + K to see them all.

A quick tour

Start from Home

The Home tab collects your connections in one place.

  • Recent connections as tiles, all the others in a list.
  • One search field for connections and for topics in the open tabs.
  • Type a broker URL to open a temporary connection.

Explore the messages

Every connection shows a live topic tree. Select a topic to see the details.

  • Payload: the last message and when it arrived.
  • History: the previous values of the topic.
  • Publish: send a new message on the topic.

Find any value

The search filters the topic tree while messages keep arriving.

  • Basic search on full topic names or leaf names.
  • Search inside the message with query::properties.userProperties.key=value.
  • Case sensitive, whole word and regular expression options.

Get notified, keep a log

Watch for the messages that matter.

  • Add one or more trigger conditions, joined with or or and.
  • Turn on desktop notifications, file logging, or both.
  • The tab and the address bar show when logging is on.

Frequently asked questions

What is MQTT5 Explorer?

MQTT5 Explorer is a free, open source desktop MQTT client. It shows the topics of a broker as a live tree, lets you read and publish messages and supports all the features of MQTT 5, such as message properties and user properties.

Is MQTT5 Explorer free?

Yes. MQTT5 Explorer is free and open source under the GNU General Public License version 3 (GPL-3.0). The source code is on GitHub.

Which operating systems does MQTT5 Explorer support?

Windows, macOS and Linux. On Linux you can install it from Flathub, from the AUR (mqtt5-explorer-bin) or as an AppImage from the GitHub releases.

Does MQTT5 Explorer support MQTT 3.1.1?

Yes. You can choose MQTT 3.1, 3.1.1 or 5.0 for each connection. MQTT 5.0 is the default.

Which connection types and security options are supported?

The mqtt://, mqtts://, ws:// and wss:// protocols. Connections can use a username and password, TLS with a CA certificate, and a client certificate and key.

Can I search inside MQTT payloads and properties?

Yes. Use the prefix query:: followed by a key path in dot notation and a value, for example query::properties.userProperties.key=value. Case sensitive, whole word and regular expression options are available.

Can I connect to more than one broker at the same time?

Yes. Each connection opens in its own tab and all tabs stay connected at the same time. A tab shows the connection state and the number of new messages it received in the background.
